# Virtual Body

A lightweight single-page spatial tracking studio landing page for a browser-based live camera interface.

## Run locally

Open `index.html` in a browser, or serve the folder via a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- The page includes a camera-start flow, fullscreen toggle, tracking controls, and animated viewport.
- Camera access requires browser permission.
- GitHub Pages can serve this project from the repository root once enabled in the repo settings.
